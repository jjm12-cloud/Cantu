# TELE PRÊMIO — demonstração visual

Protótipo estático independente inspirado no layout de referência. Não é um sorteio real. Sem parceria declarada, prémios, pagamentos, recolha de dados ou serviços externos.

Abra `index.html` num navegador ou sirva a pasta com `python -m http.server 8080`.

Fluxo: cadastro fictício → lista de valores ilustrativos → escolha de número → animação → resultado explicitamente fictício → fim. Os campos pessoais são apenas exemplos não editáveis; os valores não são enviados ou guardados. Sem dependências ou processo de build.

Vercel: usar esta pasta como Root Directory, framework Other, sem comando de build.
